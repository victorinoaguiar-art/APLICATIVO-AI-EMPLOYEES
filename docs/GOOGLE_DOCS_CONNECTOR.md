# Google Docs Connector — Manual de Operações

## Operações Suportadas
- `docs.create`, `docs.read`, `docs.update`, `docs.append`, `docs.replace_text`
- `docs.export_pdf`, `docs.export_docx`

## Estrutura de Documentos
- O Employee constrói produtos de trabalho estruturados (título, secções, tabelas, bloco de assinaturas).
- Suporte a clonagem de modelos nativos aprovados e regras de brand governance (CLBGS).
- Deteção de conflitos de versão (`DOCUMENT_VERSION_CONFLICT`).
