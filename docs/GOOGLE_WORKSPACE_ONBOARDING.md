# Onboarding de Organizações no Google Workspace (GWNIS)

## Passos de Onboarding
1. Conetar conta de organização via OAuth 2.0 / Service Account.
2. Definir âmbitos autorizados de Drive, Docs e Sheets.
3. Configurar allowlists de recursos e pastas partilhadas.
4. Associar AI Employees aos conectores autorizados.
5. Executar testes de validação antes de ativar o estado `ACTIVE`.
